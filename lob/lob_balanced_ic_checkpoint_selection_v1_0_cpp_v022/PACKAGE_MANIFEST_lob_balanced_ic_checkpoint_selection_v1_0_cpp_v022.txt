Primary selection rule
----------------------
An epoch is deployable only if TRAIN IC and TEST IC both exceed their configured minima.
Among deployable epochs:
  balanced_ic = min(train_ic, test_ic)^2 / max(train_ic, test_ic)
best.pt is the epoch with maximum balanced_ic.

Status notebook semantics
-------------------------
- Rank actual run/checkpoint candidates independently.
- Repeated seeds are not averaged or clustered for ranking.
- Main epoch chart overlays learning rate on a secondary y-axis with TRAIN IC, TEST IC and Balanced IC.
